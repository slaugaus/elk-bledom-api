# ELK-BLEDOM API

Control cheap LED strips with simple POST requests to a BLE-enabled linux box (tested on a
Raspberry Pi 4).

Personal [RIIR](https://github.com/ansuz/RIIR) of
[Amenofisch/ELK-BLEDOM-RECODE](https://github.com/Amenofisch/ELK-BLEDOM-RECODE), because I
write enough JavaScript at work.
